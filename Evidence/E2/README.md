# E2 Camera/感知/ASR/TTS 交互增强 · 操作手册（web/index.html）

> 适用版本：2026-10-05 更新后的 index.html（E2 通栏面板版）
> 实现方式：纯前端。摄像头用浏览器原生 WebRTC（getUserMedia），语音识别/合成用浏览器原生 Web Speech API（SpeechRecognition / speechSynthesis），无任何后端。
> 约束遵守：不做人脸/身份识别；感知结论标注来源与置信度并声明局限，不作为唯一环境决策依据；E2 为独立新增代码块，原有 D1-D5 与 MQTT 处理链未改动（E2 只读现有状态 + 独立 MQTT 订阅）。

## 一、前置条件

| 项 | 要求 |
|---|---|
| 浏览器 | **Chrome 或 Edge**（Web Speech API 与 file:// 摄像头均可用；Firefox 不支持语音识别） |
| 语音识别网络 | ASR 走浏览器语音服务，需联网 |
| 麦克风 / 摄像头 | 首次使用需在浏览器弹窗中允许权限；拒绝后可在地址栏图标重新允许 |
| MQTT 数据 | broker 运行 + sensor_sim.py 或 MQTTX 发报文（E2 状态卡/感知/播报依赖实时数据） |
| 打开方式 | 浏览器打开 `web/index.html`，E2 面板位于 D1 监测卡与 D2 面板之间（通栏） |

## 三、核心机制：选中区域（e2SelectedZone）

面板有一个「选中区域」状态，由标题栏胶囊标签维护，**统一驱动**：

- ASR 指令「查看 zone-w」→ 修改选中区域
- TTS 播报 → 朗读选中区域的实时数据
- Camera 拍照 → 照片绑定选中区域的 zoneId
- 状态卡片 / 感知结论 / 现场相册 / 事件日志 → 全部只显示选中区域内容

切换区域的三种方式：① 点标题栏标签；② 语音「查看 zone-w / 切换到食堂区」。

## 四、功能操作说明

### 1. 区域切换

| 操作 | 行为 |
|---|---|
| 点标签「教学区（zone-s）」等 | 标签变蓝选中；状态卡、感知结论、相册、日志立即切换到该区域 |
| 语音「查看 zone-w」/「切换到食堂区」 | 同上，并语音回读确认；识别结果框显示执行反馈 |

### 2. TTS 语音播报（内容非固定文本）

- 点「朗读当前区域状态」→ 浏览器朗读**当下实时拼装**的文本：区域名、状态、PM2.5、CO₂、人流密度与等级、感知来源与置信度、D5 规则/ML 结论及一致性
- 验证非固定文本：改一条 MQTT 报文后再次点播报，内容随新数据变化
- 拍照后自动播报一次（见第 4 节），内容为「环境 + 感知 + D5」完整结论

### 3. ASR 语音识别（两条业务指令）

| 指令 | 触发功能 |
|---|---|
| 「查看 zone-w」/「查看 食堂区」/「切换到 教学区」 | 修改选中区域（含中文名与 zoneId 两种说法；ASR 把 zone-w 听成 "zone w" 也能归一化匹配） |
| 「记录现场」 | 触发拍照存档 + 写入事件日志 + TTS 播报感知结论（摄像头未开启时给出失败反馈） |

操作：点「开始语音识别」→ 允许麦克风 → 说话 → 识别结果与执行反馈显示在反馈框 → **自动续听**（一条说完继续听下一条）→ 点「停止语音识别」结束。

### 4. Camera 拍照（每张绑定 zoneId / 时间戳 / 事件状态）

1. 点「开启摄像头」→ 允许权限 → 取景框出现实时画面，「记录现场 · 拍照存档」按钮激活
2. 点「记录现场」→ 抓取当前帧 → 照片存入**页面内存**（刷新即清空），绑定信息：
   - `zoneId`：拍照时的选中区域
   - `time`：抓拍时刻（精确到秒）
   - `eventState`：该区域当前 D3 事件状态（OPEN 待处理 / HANDLING 处理中 / RECOVERED 已恢复 / 无事件）
3. 同一区域可连拍多张（不同角度/光照），相册正常加载
4. 拍照同时：写入事件日志；若该区域存在活跃 D3 事件，追加到该事件 historyNotes（与 D3 记录真合并）；自动 TTS 播报感知结论

摄像头错误提示对照：NotAllowedError（权限被拒）/ NotFoundError（无设备）/ NotReadableError（被占用）/ 非安全上下文。

### 5. 现场相册（内存回看）

- 只显示选中区域的照片，最新在前，显示总数
- 点击缩略图 → 灯箱大图 + 完整元信息（区域、完整时间戳、事件状态）
- 点「关闭」或点击黑色背景关闭；刷新页面相册清空（内存存储，符合规格）

### 6. 感知结论与低置信度警告

感知结论行 = 人流等级（中文 + L 数值）+ 来源标记 + 置信度：

- 来源类型：`simulated` / `rule` / `review`（声明来源，按规则置信度取 1.0）；`model` 等自动感知来源必须携带 confidence
- **低置信度警告**：自动感知来源且 confidence < 0.2 → 红色警告条「⚠ 低置信度警告：置信度低于 0.2 阈值，该感知结论仅作参考，需人工复核，不作为唯一环境决策依据」
- 感知结论下方常驻局限声明：结论标注来源与置信度，不作为唯一决策依据
- 联动：低置信度时 D2 表格同步标注「需人工复核」，D3 恢复条件同时受阻（原有逻辑）

### 7. 事件与抓拍日志（与 D3 事件记录合并）

单列表展示选中区域三类条目，按 活跃事件 → 抓拍（新→旧）→ 已恢复事件（新→旧）排列：

| 条目 | 徽标 | 内容 |
|---|---|---|
| D3 活跃事件 | 黄色 D3 | 事件 ID、OPEN/HANDLING、异常描述、处置措施 |
| 现场抓拍 | 紫色 抓拍 | 时间、事件状态、存档说明 |
| D3 已恢复 | 黄色 D3 | 事件 ID、恢复结论 |

照片同时写入 D3 事件的 historyNotes，事件恢复后在 D3「历史事件（已恢复）」的补充记录中可见「[现场拍照] …图片已存档至 E2 相册」。

## 五、完整交互链（任务书验收主场景）

```
语音指令【查看 zone-w】→ 选中区域切换为食堂区 zone-w（标签变蓝、状态卡切换）
        → 点击/语音【记录现场】→ 摄像头拍照存档（绑定 zone-w / 时间戳 / 当前事件状态）
        → 感知给出 crowdLevel 拥挤结论（含来源与置信度）
        → TTS 朗读该区域环境 + 感知 + D5 结论
```

操作复现：

1. 开启语音识别 + 开启摄像头，选中区域停在 zone-n
2. 说「查看 zone-w」→ 听到确认语音，选中区切换
3. 说「记录现场」→ 自动拍照、相册 +1、日志 +1，TTS 播报「食堂区。感知结论：人流密度…，等级…，来源…，置信度…。环境状态：…。D5判定：…」

## 六、验收流程（对应任务书条款）

| 任务书条款 | 验证步骤 | 通过标准 |
|---|---|---|
| ASR ≥2 条指令，≥1 条改选中区域/触发功能 | 语音「查看 zone-w」「记录现场」 | 前者切换选中区域并语音确认；后者触发拍照+播报 |
| TTS 朗读实时状态非固定文本 | 播报 → MQTTX 改数值 → 再播报 | 两次内容随数据变化 |
| 拍照存内存 + 绑定三要素 + 相册回看 + 同区域 ≥2 张 | 连拍 3 张 → 点缩略图 | 每张大图显示 zoneId/完整时间/事件状态 |
| crowdLevel 来源标记 + 置信度 <0.2 警告 | 发 `crowdSource:"model", crowdConfidence:0.15` 报文 | 感知结论显示来源 model/置信度 0.15 + 红色警告条 |
| 完整交互链 | 第五节流程 | 语音→切换→拍照→感知→播报全程闭环、无刷新 |
| 拍照自动写入事件日志并与 D3 合并 | 造 D3 事件 → 拍照 → 恢复 | E2 日志两类条目共存；D3 历史详情含拍照补充记录 |
| 切换选中区域后全模块跟随 | 逐个标签切换 | ASR 目标、TTS 文本、拍照绑定、状态卡、相册、日志全部跟随 |
| 不破坏 D1-D5 / 无人脸识别 | 全程观察 + 代码审查 | D1-D5 各面板行为不变；代码无任何识别类处理 |

低置信度测试报文（MQTTX → `airguard/zone-w/env`，time 用当前时间递增）：

```json
{"zoneId":"zone-w","pm25":40,"co2":700,"crowdLevel":2,"crowdSource":"model","crowdConfidence":0.15,"time":"当前时间"}
```

## 七、常见问题

| 现象 | 原因与处理 |
|---|---|
| 提示浏览器不支持语音识别 | 换 Chrome/Edge；Firefox/Safari 不支持 Web Speech API |
| 识别一直「未检测到语音」 | 麦克风权限被拒（地址栏重新允许）或麦克风被占用 |
| 摄像头开启失败 | 按错误码处理：NotAllowedError 允许权限、NotFoundError 接设备、NotReadableError 关闭占用程序 |
| 拍照按钮灰色 | 未开启摄像头，先点「开启摄像头」 |
| 听不到播报 | 检查系统音量与 Windows 语音合成包（设置→时间和语言→语音） |
| 相册刷新后清空 | 符合规格：照片仅保存在页面内存 |
| 状态卡数值不动 | 该区域无新报文；MQTT 数据停发则定格 |
